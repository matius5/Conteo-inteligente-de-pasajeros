# Guía para incorporar evidencias del ABPr

Este documento organiza **archivos reales obtenidos por el equipo**. No se han añadido capturas o resultados simulados.

## Archivos sugeridos

| Ruta propuesta | Qué mostrar | Estado |
| --- | --- | --- |
| `evidencias/pruebas_pc/deteccion_yolo.png` | Captura de detección desde cámara del portátil | Pendiente de recibir |
| `evidencias/pruebas_pc/conteo_cruces.png` | Contadores de entradas y salidas visibles | Pendiente de validar |
| `evidencias/videos/README.md` | Enlaces a videos de pruebas con fecha | Pendiente |
| `hardware/esquematico/` | Proyecto KiCad y exportación PDF/PNG real | Pendiente |
| `hardware/pcb/` | Archivos `.kicad_pcb` y capturas de pistas | Pendiente |
| `evidencias/integracion/` | Fotos de Raspberry Pi, ESP32 y OLED conectadas | Pendiente |

GitHub no conserva carpetas vacías. Créalas al subir su primer archivo o usa un `.gitkeep`.

## Formato de bitácora por prueba

- Fecha y responsables:
- Dispositivos y modelos:
- Script ejecutado y comando:
- Versión del modelo YOLO:
- Orientación y coordenadas de la línea:
- Condiciones de iluminación:
- Número de entradas/salidas reales:
- Número de entradas/salidas detectadas:
- Fallos observados:
- Ruta de fotografía o video:

No presentar la cámara, la PCB, los pesos del modelo ni los datos de exactitud como validados hasta haber realizado dichas pruebas. Evitar publicar imágenes identificables de pasajeros sin permiso.
